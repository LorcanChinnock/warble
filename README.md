Warble shows what's playing in the notch at the top of your Mac's screen. Hover over the notch or click it to see the song, then play, pause, skip, scrub, change the volume or switch speakers. When nothing is playing, Warble draws nothing and uses no CPU.

It works with Apple Music, Spotify, podcasts and video in your browser. Macs without a notch, and external displays, get a virtual one.

Warble isn't released yet. [docs/roadmap.md](docs/roadmap.md) lists what each release will include, with a link to each release's issue.

## Privacy

Warble collects nothing. It has no account, no cloud and no analytics, and it only goes online to check for updates, after you agree.

## Contributing

Bug reports, ideas and pull requests are welcome. [CONTRIBUTING.md](CONTRIBUTING.md) explains how to build Warble from source, run the tests and send a change. To report a security problem, see [SECURITY.md](SECURITY.md).

Warble shares its repository layout, tooling and release pipeline with [Shot](https://github.com/LorcanChinnock/shot), a screenshot app by the same author.
