# Website

Read this before changing `site/` or the user guide. Back to the [architecture index](../../CLAUDE.md#architecture).

`site/` is the Astro site for warble.lorcanchinnock.com, deployed from each release's tag by `.github/workflows/site.yml`, which `release.yml` calls, so it describes the version people can install. Merging a site change to `main` doesn't deploy it (see `site/README.md` › Deploying). The user guide lives in `site/src/guide/`, one Markdown file per page at `/docs/<slug>/`, in file name order. Each file's front matter gives its `title`, a one-line `summary` and its `group` (the groups are in `site/src/lib/guide-files.ts`). Write pages as tasks, in second person: numbered steps, `<kbd>⌘⇧4</kbd>` for keys, and `> [!TIP]` or `> [!NOTE]` callouts. The site also renders `CHANGELOG.md` directly. The landing page's `#install` section holds the steps to open Warble past Gatekeeper, and the Homebrew cask's caveat (`scripts/homebrew-cask.sh`) links to it, so keep that anchor. release-please ignores `site/`. The site's look is Warble's own, not Shot's: black, quiet, gone when not needed. It uses the notch's black, white and greys in the system font, with no accent colour. Its one colour is a glow like the one the open card takes from the artwork, and light and dark follow the system. The tokens are at the top of `site/src/styles/global.css`. Only the footer's "LC_" mark and "Made by Lorcan Chinnock", the voice and the copy button carry over from Shot.
