# Accessibility

Read this before adding or changing any control or label. Back to the [architecture index](../../CLAUDE.md#architecture).

Every notch control has a VoiceOver name, and what's playing reads "Now playing: <title> by <artist>". Nothing is shown by colour alone: shuffle and repeat draw a dot when on, the mute button's name says what a click does ("Mute" or "Unmute") while its symbol gains a slash, and the heart for Music's Favourites is filled when the song is a favourite and an outline when not, named "Remove from Favourites" or "Add to Favourites". Increase Contrast lightens `Native.secondary` and `Native.track` and swaps the glow for a border. Reduce Motion keeps the glow still, instead of drifting. Settings is made of system controls, which bring their own names, roles, keyboard focus and Increase Contrast. A `Toggle` or `Picker` in a `Form` whose label has two `Text`s reports no name of its own, so `described(_:_:)` (`SettingsView.swift`) gives it the title as `.accessibilityLabel` and the second line as `.accessibilityHint`; use it on every such row, then check the name in the Accessibility Inspector. A one-line `Picker` in a grouped form reports only its value, so it names itself with `.accessibilityLabel`. A `LinkRow` reads as a link named by its title, with what it opens ("Release notes", "MIT") as its value. Its label has 6 points of room inside, taken back outside so the row doesn't move, and a rounded focus shape, so the keyboard focus ring sits clear of the text rather than on its edges. About's status line reads as one element, its text; the dot beside it is hidden, and the text says the same thing, so the dot's colour is never the only signal. The tabs are the toolbar's own buttons. The menus are standard menus, which VoiceOver and the keyboard reach as usual. The menu bar icon is named "Warble", or "Warble, update available" while an update waits, so the dot isn't the only signal; the update item's title says the same, and the dot after it is a text attachment, so the item sets its VoiceOver name to the title alone, without the attachment's U+FFFC. The update window is system controls too, and announces its title when it opens. Its titles are headings, and so are the release notes' version numbers and group names; the icon is hidden, since the title names the app. The download's progress bar is named by the title, with the sizes and the time left as its value. Return presses the default button, and Esc and the close button do what closing that state does (`UpdatePhase.closing`). With keyboard navigation on, the Notch tab starts with focus on its first setting, Stay visible after pausing, rather than on the preview above it; with it off, nothing takes focus until it's clicked. The notch preview is a button named "Notch preview", valued Open or Closed, which a press from the keyboard or VoiceOver opens and closes, and which takes keyboard focus only while keyboard navigation is on, as a button does; what it draws is part of that one button, so VoiceOver never reaches its controls, which do nothing. Yellow is never text, and a switch's state also shows by its knob's position. Increase Contrast darkens a switch that's on to `Color.warbleGold` and gives the Size segments the system's own high-contrast look ([Design](design.md)). A long translation wraps rather than cutting off: a link row's value wraps beside its name, and the offer's three buttons stack, default first, when two side by side don't fit.
